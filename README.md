        Overview
Go-Cal is an NCERT-focused smart calculator designed to help students
solve math problems with clear, step-by-step explanations.
It combines structured logic with AI-assisted reasoning.

        Why Go-Cal Exists
Many students struggle not because they lack effort,
but because solutions skip reasoning steps.
Go-Cal focuses on **clarity, correctness, and learning**, not just answers.

        How It Works (High-Level)
- Users input a math problem
- The system analyzes the question structure
- AI-assisted logic generates step-by-step explanations
- Usage limits and subscriptions are managed securely

         Tech Stack
- Frontend: Web (HTML/CSS/JavaScript)
- Backend: Supabase (Auth, Database)
- AI Logic: Edge / server-side functions
- Hosting: Managed platform (not static)
